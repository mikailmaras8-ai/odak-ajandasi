## ✨ Özellikler

- **⏱️ Derin Odak & Pomodoro:** Özel zamanlayıcı, mola aralıkları ve odaklanma seansları.
- **🎧 Ambiyans Sesleri:** Yağmur, Kafe, Orman ve Okyanus dalgaları ile dikkat dağıtıcıları engelleyin.
- **🌲 Sanal Orman:** Tamamlanan her odaklanma seansında büyüyen sanal ağaçlar ve başarı rozetleri.
- **🎯 Günlük Hedef Takibi:** Günlük odaklanma dakikanızı belirleyin, ilerlemenizi dairesel halkayla takip edin.
- **⚡ %100 Çevrimdışı Desteği (PWA):** İnternet olmasa dahi anında açılır ve çalışır.
- **☁️ Supabase Bulut Eşitleme:** Oturum açarak tüm verilerinizi ve ağaçlarınızı telefon ve bilgisayarınız arasında anında eşitleyin.

## 📱 Telefona Kurulum (PWA)

Uygulama herhangi bir uygulama mağazasına (App Store / Play Store) ihtiyaç duymadan doğrudan telefonunuza native bir uygulama gibi kurulur:

### 🍏 iPhone / iPad (iOS):
1. Safari tarayıcısında canlı bağlantıyı açın.
2. Alttaki **Paylaş** (kare içinden yukarı ok) simgesine dokunun.
3. Menüyü aşağı kaydırıp **"Ana Ekrana Ekle"** seçeneğini seçin.
4. Sağ üstteki **"Ekle"** butonuna basın.

### 🤖 Android:
1. Google Chrome tarayıcısında canlı bağlantıyı açın.
2. Sağ üstteki **üç nokta** menüsüne dokunun.
3. **"Uygulamayı Yükle"** veya **"Ana Ekrana Ekle"** seçeneğini seçin.

## 🚀 Yerel Geliştirme

Projeyi bilgisayarınızda çalıştırmak için:

```bash
# Depoyu klonlayın
git clone https://github.com/mikailmaras8-ai/odak-ajandasi.git
cd odak-ajandasi

# Basit bir HTTP sunucusu başlatın
python3 -m http.server 8080
# Tarayıcınızda açın: http://localhost:8080
```
